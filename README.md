# Social Copywriter Skill

一个面向自媒体创作者的 AI 文案与选题辅助工具。

这个 Skill 主要用来解决创作过程中最常见的两个问题：  
一是**有图片、视频或想法，但不知道怎么写成一条合适的文案**；  
二是**暂时没有素材，但想先看看近期适合创作什么内容方向**。

它可以根据用户提供的素材描述、主题想法、内容类别、发布平台和文案风格，生成更适合发布场景的标题、正文、标签和内容方向建议，帮助创作者更快完成从“想发”到“能发”的过程。

## 适用场景

这个工具主要适用于以下几类创作需求：

- 有图片或视频内容，但不会组织语言
- 有一个想表达的主题，但不知道怎么展开
- 想发日常、风景、美食、经验分享、学习记录、旅行探店等内容
- 想获得更贴近平台风格的文案建议
- 没有现成素材时，想先获取一些可拍、可写的内容方向

## 核心能力

- 根据素材或描述生成标题、正文、标签和互动引导
- 支持从主题出发生成完整文案结构
- 提供适合不同内容类别的表达建议
- 根据不同平台调整文案语气和写法
- 在无素材场景下提供近期适合创作的选题方向
- 尽量减少空泛、模板化、AI味过重的表达，让内容更接近真实创作者的自然输出

## 适合谁使用

适合想提升内容产出效率的个人创作者、自媒体账号运营者，或者经常需要为图文和短视频内容撰写文案的人使用。
