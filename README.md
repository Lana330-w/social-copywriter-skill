# 🐱 自媒体文案小助手 Skill

帮你根据图片生成小红书/抖音/微博文案，或推荐热门话题创作方向。

## 功能

- **图片 → 文案**：上传照片，自动识别内容，生成适合各平台的爆款文案
- **热点推荐**：根据你的内容方向，推荐当下热门话题和拍摄建议

支持内容类型：猫咪/宠物、日常生活、风景旅行、美食、经验分享、学习记录

## 安装方法

1. 下载 `social-copywriter.skill`
2. 打开 [Claude.ai](https://claude.ai) → 左下角头像 → Settings → Skills
3. 点击 Upload Skill，上传文件
4. 新开一个对话即可使用

## 使用方式

**生成文案**
> 上传一张图片，说"帮我写小红书文案" 或 "这张图发什么好"

**热点推荐**
> 说"最近什么话题火" 或 "我想拍美食，有什么热门选题"

## 支持平台

小红书 · 抖音 · 微博 · 朋友圈
